# Live Orders

Every order for your shop, newest first.

## Finding an order

- **Search** by order number (for example `ORD-2026-00047`), customer name, phone or email.
- **Status filter:** Active (hides archived history), All statuses, Awaiting deposit, Confirmed, Changes open, Locked, In preparation, Ready, Collected, Completed / archived, Archived, Voided / cancelled, Draft.
- Other filters such as pickup date and "price TBC" are available where shown.

## Order statuses

| Status | Meaning |
|---|---|
| **Awaiting deposit** | Order placed, deposit not paid yet. |
| **Confirmed** | Deposit paid (or no deposit needed). |
| **Changes open** | The customer can still edit the order. |
| **Locked** | Past the cutoff — customers can't change it any more. |
| **In preparation / Ready** | Being made up / ready to collect. |
| **Collected / Completed** | Picked up and finished. |
| **Archived** | Imported history from earlier seasons (used for "Order again"). |
| **Voided / cancelled** | Cancelled by staff. Can be restored. |

## How to

1. **Open an order:** click the row. The full order screen opens (see **Order screen**).
2. **Chase deposits:** filter to *Awaiting deposit* and press **Send deposit reminders**.
3. **Find last year's order for a customer:** choose *All statuses* or *Archived* and search their name or phone.

## Good to know

- Orders marked **Important** show a coloured flag so the team notices them.
- Deposit reminders also go out automatically if switched on in **Settings → Tax & Payments**.

## FAQ

**I voided an order by mistake.** Filter to *Voided / cancelled*, open it and press **Restore order**.
