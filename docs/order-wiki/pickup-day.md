# Pickup Day View

The operational screen for a single pickup day.

## How to

1. Pick the date and press **Load day**.
2. Orders are grouped by pickup time window. Click one to open it.
3. Use the filter chips to focus:
   - **All**
   - **Exceptions** — anything that needs attention.
   - **Important** — flagged orders.
   - **Notes** — orders with customer or staff notes.
   - **Unpaid** — deposit still owing.
   - **Price TBC** — items not yet weighed.
   - **Change requests** — waiting for approval.
4. Print what you need: **Print run sheet**, **Print exceptions**, **Print labels**.

## Good to know

- Orders with a pickup set using **Other date…** appear on that day like any other.
- **Production Summary** gives the totals for the same day (what to prepare); Pickup Day View is about the customers collecting.

## FAQ

**An order is missing from the day.** Open it and check its pickup date — it may have no date or a different one.
