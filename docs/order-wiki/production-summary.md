# Production Summary

Shows the totals you need to prepare for a pickup date.

## How to

1. Choose the pickup date and press **Load supply**.
2. Read the product totals: how many of each item, sizes and estimated weights.
3. Print:
   - **All orders (packing slips)**
   - **Pick list (one page)**
   - **Prep summary**
   - **Procurement checklist** (what to buy)
   - **Allocation checklist**
   - **Order labels** / **Item stickers**
   - **AirPrint day run** (for printing from an iPad or iPhone)
4. **Lock this date** stops customers changing any order for that pickup date (you'll be asked to confirm).

## Good to know

- Prints are remembered: if orders change after you printed, the screen tells you "changes since print".
- **Product search sheet** finds every order containing a product (for example every Half Ham 4–4.5 kg).
- **Open Product Allocation** jumps to the packing checklist for the same day.

## FAQ

**Totals don't match the stock I have.** Production Summary counts what's *ordered*. To match orders to the actual hams and turkeys you've received, use **Stock**.
