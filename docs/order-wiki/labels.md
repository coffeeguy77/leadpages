# Labels & Stickers

## How to

1. Choose the pickup date.
2. Press **Print order labels** (one per order) or **Print item stickers** (one per item).
3. Print on two-up A4 sticker sheets (about 92 × 48 mm per sticker).

Each label shows the customer, pickup window and a **QR code** that opens the customer's order page.

## Good to know

- Orders marked **Important** show an Important badge on labels when "Show on labels" is turned on in the order's Importance card.
- You can print labels for a single order from the order screen (**Print order label** / **Print item stickers**).
- The system remembers what was printed and tells you if orders changed since.

## FAQ

**The QR code opens leadpages.com.au, not our website.** Links switch to your own domain once it's live and pointing at LeadPages. Old labels still work either way.
